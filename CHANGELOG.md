# Изменения

## 1.4.0 — 15 октября 2026

- Windows и Linux: удаление работы с подтверждением и удалением связанных часов и поправок.
- Выбор работы из виджета без изменения состояния независимых таймеров; сохранены настройки прозрачности.
- Автоматическая проверка обновлений сразу при запуске и не чаще одного раза в 24 часа.
- Ручная проверка обновлений остаётся доступной при отключённой автоматической проверке.
- Релизные сборки Windows и Linux обновлены до 1.4.0.

## 1.3.0 — 14 октября 2026

- Windows и Linux: проверка стабильных релизов GitHub раз в сутки и вручную из трея.
- Скачивание обновлений после подтверждения, проверка размера и SHA-256 файла.
- Windows: замена исполняемого файла, резервная копия и восстановление при неудачном запуске.
- Linux: скачивание `.deb`, установка через системный запрос прав администратора
  или команда для ручной установки.
- Сохранение часов перед перезапуском и возобновление активных работ.
- Настройка для отключения автоматической проверки; проверки обновлений в CI.

## 1.2.0 — 14 октября 2026

- Windows и Linux: работы с названиями, независимыми таймерами и историей по дням.
- Одновременный учёт нескольких работ и пауза всех работ через трей.
- Переименование без потери часов, ручные поправки и CSV для выбранной работы.
- Название выбранной работы в основном окне и плавающем виджете.
- Совместимый формат данных для переноса между Windows и Linux; старые данные
  автоматически относятся к «Общей работе».
- Сборка и проверки обеих платформ в GitHub Actions, публикация двух пакетов по тегу версии.

## 1.1.1

- Исправлены команда горячей клавиши и повторный запуск Linux-приложения.
- Добавлены сборка Debian-пакета и проверка установленного приложения.
